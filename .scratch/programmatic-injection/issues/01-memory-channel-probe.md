# 01 — Prove the custom-instruction/memory injection channel exists (E-O2 pilot)

**Status:** ready-for-agent

**Type:** research

## Context

We want to inject proxy steering into M365 Copilot programmatically. The
cheapest, no-approval lever is the account **custom-instructions** channel
(empty, settable textarea) + the `add_custom_instructions` /
`update_memory_plugin` / `enable_inferred_memory_read` optionsSets flags the
GUI already sends. Whether an API-driven turn actually writes mailbox-backed
memory keyed by `oid` and recalls it cross-conversation is **unverified**
(H8.14). GLM-5.2 challenged the whole "durable memory slot" idea as possibly
license-gated on Basic — this probe settles it before we build anything on it.

## Probe (E-O2, zero new code — uses existing plumbing)

1. **Pre-flight:** open the GUI Custom Instructions panel
   (`Settings → Personalization`). Greyed-out toggle = tenant-disabled → abort,
   zero threads spent. (Done 2026-08-11: toggle is ON; textarea empty.)
2. **Pilot (≤4 threads):** `scripts/_probe-chat.mjs` with
   `optionsSets: ["add_custom_instructions","update_memory_plugin","enable_inferred_memory_read"]`.
   - Turn 1: plant a unique nonce code word as a memory/instruction.
   - NEW conversation, read-flag on: ask for the nonce's mapping-reply.
   - Cross-conversation recall = durable channel confirmed.
3. **Attest (optional):** read the mailbox-backed artifact back via Graph
   `Mail.ReadWrite` (token carries it) and diff against the intended payload —
   do not trust the model's echo.
4. **n=1 caveat** (AGENTS.md): pilot results CANNOT conclude; needed ≥1
   replicated run (≥3 flag-on/off pairs, rotated, rested account) if it looks live.

## Criticism to carry

- **Mapping-canary:** recall must ask for a reply known ONLY to the injected
  text, never shown in the prompt — else the model echoes context and the probe
  false-positives.
- **8,000-char silent truncation** (H8.15) may strip long payloads.
- GLM-5.2's challenge: Basic may not be entitled to author Studio memory. If
  the panel is greyed or the write silently no-ops, that CONFIRMS the challenge
  and kills the durable-slot idea — record it.
