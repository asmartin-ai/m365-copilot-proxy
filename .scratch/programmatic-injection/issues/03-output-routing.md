## Design

The proxy already routes fenced ```` ```bash ```` blocks to the shell tool
(AGENTS.md shell-routing). This ticket hardens that into a disciplined
output-boundary contract:

- **Route/interleave, never rewrite.** Keep the existing fence-routing (correct
  and shipped). Do NOT rewrite Copilot prose into tool calls — that fabricates
  model intent and breaks multi-turn coherence.
- **Canary for steering attribution.** Injected steering carries a distinct
  codeword→reply mapping per channel; the proxy routes a fence ONLY when it can
  attribute the response as steered (channel fingerprint), degrading cleanly to
  raw text when unsteered.
- **Disengagement-drift guard.** Merging GUI flags (`add_custom_instructions`
  etc.) changes the Prompt-Shields shape balance (F22/F17). Add a drift check:
  watch `usage.x_m365_dea_score` and Disengaged rate under injection vs
  baseline; alert if injection raises either. (GLM flagged this.)
- **`system_fingerprint` contract.** Expose `'steered:channel=X'` |
  `'unsteered'` on responses so downstream agents can gate their own behavior.
